# Day 1 Implementation Plan

Date: 2026-04-25
Status: Implemented and locally verified

## Top-level items worked through

### 1. Implementation-ready plan

1. **Streaming target**: HLS is the v1 default. It matches the intended delayed-live model, can be generated by FFmpeg, and can be served as static files from `public/stream/`.
2. **Symbolic contracts**: the design now defines three explicit contracts: future role-agent output bundles, the flat internal event list consumed by the renderer, and the `state.json` website state consumed by the listener page. Day 1 implements the flat event and website state contracts; Day 2 will transform role bundles into flat events.
3. **Coordinator model**: the conductor owns canonical tempo, key, chord grid, section, active soloist, deadlines, and reset behavior. Role agents can propose musical material, but the conductor validates and commits it.
4. **Prompt and fallback contract**: the design now includes copy-paste v0 conductor and shared role prompt templates, plus role-specific constraints. Invalid or late output falls back to repeat/variation, safe support pattern, reset motif, or one-segment mute.

### 2. Day 1 skeleton

Day 1 implements the project scaffold, deterministic role events, MIDI output, MIDI-derived audio rendering, rolling live-style HLS output, a static listener page, and a recording artifact. This proves the riskiest local media path before LLM agents are added. The Day 1 `state.json` is not a role-agent bundle; it is the documented website state contract.

### 3. Intelligence plan

The intelligence layer is not implemented on Day 1. It will replace the deterministic event builder with role-agent calls that emit role-agent output bundles. The conductor will validate those bundles, flatten them into the internal event list, and then pass the flat events to the same renderer path used by Day 1. The conductor state machine will own deadlines, validation, reset behavior, and prompt-to-state updates.

### 4. Website and demo polish plan

Day 1 includes the static listener page and playing-status role cards. Later polish should add contributor prompt gating, richer instrumentalist animations, a visible prompt influence panel, fallback controls, and deployment hardening.

## Verification commands

```bash
python3 scripts/generate_dummy_stream.py
python3 scripts/qa_live_hls.py public/stream/index.m3u8 --startup-timeout-seconds 45 --sample-gap-seconds 6 --min-start-sequence 1
ffmpeg -v error -i http://127.0.0.1:8765/public/stream/index.m3u8 -t 3 -f null -
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 public/recordings/dummy-live-recording.mp3
python3 -m json.tool public/stream/state.json
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765/web/` to test browser playback.
